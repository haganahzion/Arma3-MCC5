# MCC Sandbox 5 Wiki

MCC Sandbox 5 (Mission Control Center, version 5.0.1) is an Arma 3 mod for building and running missions. You work in two places:

- **The Eden editor.** A new **MCC 5** menu in the top menu bar holds all mission settings, an editor Mission Wizard that builds a whole mission for you, and quick placement of MCC modules.
- **Zeus.** Players allowed to use MCC get Zeus in game. An **MCC 5** button at the top of the Zeus screen lists every MCC tool.

Behind both sits **GAIA**, the MCC AI commander. GAIA moves AI groups around their zones, uses vehicles, coordinates attacks and can call artillery, CAS and reinforcements.

The old MCC main menu is gone. Everything it did is now a Zeus module, an Eden module or an Eden attribute.

> The release notes say this build has not been tested in game yet. If something breaks, please report it with your RPT log. See [Troubleshooting](troubleshooting.md).

## Requirements

- Arma 3 (current version)
- **CBA_A3** (required)

Optional mods. MCC detects them on its own and works with or without them:

- ACE3
- RHS
- CUP
- LAMBS Danger.fsm
- LAMBS Suppression
- HBQ Advanced Driving AI

Do not load an older MCC version at the same time as MCC 5. Missions made with older MCC versions are not supported.
